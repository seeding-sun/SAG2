# SAG2 实验臂命名规范

> 生效：2026-11-14  
> 旧名（A1 / D1 / D1B1 …）一律废弃；下文「对照表」保留以便读旧文档。

---

## 1. 格式

```text
{检索}{评分}-H{扩展轮数}-{判定模型}[.-后缀]
```

四段缺一不可（后缀可选）。

### 1.1 检索（一位字母）

| 码 | 含义 |
|---|---|
| **A** | BM25（稀疏 / 词项） |
| **B** | Hybrid（BM25 + 向量 RRF） |
| **C** | Dense（纯向量，`bge-m3`） |

### 1.2 评分（一位数字）

| 码 | 含义 |
|---|---|
| **2** | 二值 binary（`scoring_scale=binary`） |
| **6** | 六档 grade（锚点 0/2/4/6/8/10，`scoring_scale=grade`） |

> 不再使用 **D** 表示六档——与「第 D 组实验 / dense」易混。

### 1.3 扩展（`H` + 数字）

| 码 | 含义 |
|---|---|
| **H0** | `max_hops=0`，不扩展 |
| **H1** | `max_hops=1`，扩展一轮 |
| **H2** | `max_hops=2`，扩展两轮 |

### 1.4 判定模型

与网关 `--evidence-model` / `config.evidence_model` **完全一致**的 slug，例如：

- `qwen3.8-27b`
- `qwen3.6-27b`
- `qwen3.5-122b-a10b`
- `gemma4-26b-a4b`

### 1.5 可选后缀

仅用于探针 / 半成品，用 `.` 连接，例如：

- `.tau02-4hop` — 阈值 τ=0.2、仅 4-hop 子集
- `.partial-30q` — 未跑完
- `.incomplete-27q` — 中止残留

---

## 2. 示例

| 臂名 | 解读 |
|---|---|
| `A2-H1-qwen3.8-27b` | BM25 × 二值 × 扩展 1 次 × 3.8-27B |
| `A6-H1-qwen3.8-27b` | BM25 × 六档 × 扩展 1 次 × 3.8-27B |
| `B2-H1-qwen3.8-27b` | Hybrid × 二值 × H1 × 3.8 |
| `B6-H1-qwen3.8-27b` | Hybrid × 六档 × H1 × 3.8 |
| `C2-H1-qwen3.8-27b` | Dense × 二值 × H1 × 3.8 |
| `C6-H1-qwen3.8-27b` | Dense × 六档 × H1 × 3.8 |
| `A2-H0-qwen3.5-122b-a10b` | BM25 × 二值 × 不扩展 × 122B |
| `A2-H1-qwen3.6-27b` | BM25 × 二值 × H1 × 3.6 |
| `A2-H1-gemma4-26b-a4b` | BM25 × 二值 × H1 × Gemma |

矩阵速记：

| | 二值 `2` | 六档 `6` |
|---|---|---|
| **A** BM25 | `A2-H…` | `A6-H…` |
| **B** Hybrid | `B2-H…` | `B6-H…` |
| **C** Dense | `C2-H…` | `C6-H…` |

## 4. 书写约定

1. 口头可说「A2」「A6」，书面首次出现写全名。
2. 文档里旧名首次出现时括注新名，例如：`D1-27B`（现 `A6-H1-qwen3.8-27b`）。
3. 新跑臂的 `--output-dir` **必须**用新名；链式脚本已按此更新。
4. 比较脚本路径跟着目录名走，不再使用 `A1`/`D1` 缩写作为目录。
