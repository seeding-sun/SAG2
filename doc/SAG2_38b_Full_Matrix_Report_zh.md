## 4. 分析

### 4.1 扩展：二值与六档行为不同

- **六档**：增益几乎全在 H0→H1；H1→H2 三检索均为负或接近 0。最优点在 **H1**。
- **二值**：A/B 的 **H2 仍有可见增益**（A +3.6pp，B +4.3pp）；Dense 的 H2 反而略掉。最优点在 **B2-H2**。

与论文「第二轮边际变薄」相比：六档更极端（边际为负）；二值 Hybrid/BM25 仍吃得到第二轮。

### 4.2 检索：入口优势如何穿过扩展

| 阶段 | 排序（R@10） |
|---|---|
| 初始池 | Dense > Hybrid > BM25 |
| 二值 H0 | Dense ≥ Hybrid > BM25 |
| 二值 H2 | **Hybrid > BM25 > Dense** |
| 六档 H1 | **BM25 ≥ Dense > Hybrid** |

结论：

1. **不扩展时向量/混合更好**——继承初始池。
2. **六档 + 一轮扩展**后 BM25 最好；Hybrid 在六档下一直偏弱。
3. **二值 + 两轮扩展**时 Hybrid 反超，成为全表第一——说明「二值填充种子 + 混合入口 + 第二轮扩展」是另一条有效路径，与「六档去填充 + BM25」不是同一机制。

### 4.3 六档还值不值得用

- 相对同检索的二值 H1：A +4.25pp、C +2.67pp、B 几乎无差。
- 但二值走到 H2 后，`B2-H2`（0.7275）超过了六档最好的 `A6-H1`（0.7142），尽管配对不显著。
- **六档的价值在「一轮扩展就够、且强化 BM25」**；若允许 H2 且用 Hybrid，二值可以打到更高点。

### 4.4 可支持 / 不可支持

**可以支持：**

- 在 3.8 上，扩展对最终召回有效；六档下主要在第一轮，二值下 A/B 第二轮仍有贡献。
- 全表最高为 Hybrid×二值×H2；六档最高为 BM25×六档×H1。
- H0 上 Dense/Hybrid 优于 BM25；扩展后排序会翻转。

**不能支持：**

- 「H2 在六档上继续有增益」（本矩阵三检索都不支持）。
- 「B2-H2 显著优于 A6-H1」（Holm p=1）。
- 「Dense 在扩展后仍保持入口优势」（二值/六档扩展后均不再领先）。
